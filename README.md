# Ammar Khandoker — Personal Portfolio

**Live website:** https://ammar.bond/

A responsive personal portfolio presenting Ammar Khandoker's professional experience, skills, learning credentials and selected digital projects.

## Website sections

- **Home** — professional introduction and primary actions
- **About** — working approach and selected career outcomes
- **Skills** — HR and operations, Excel/MIS, ERP, digital marketing, AI tools and a separate learning roadmap
- **Experience** — five career entries with expandable responsibility details
- **Certificates & Learning** — searchable course credentials and a featured government freelancer credential
- **Projects** — SML Inventory ERP case study and portfolio website
- **Contact** — email, WhatsApp, CV download and professional profiles

## Featured project

The portfolio includes a dedicated case study for **SML Inventory ERP**, a Firebase-backed inventory management system for Step Media Ltd.

## Technology

This is a static website built with semantic HTML, responsive CSS and vanilla JavaScript. No frontend framework or package build step is required.

## Deployment and maintenance

The site is published from the repository's main branch and uses the custom domain configured in CNAME.

When updating assets:
1. Update the relevant HTML, CSS or JavaScript file.
2. Increase the CSS or JavaScript query-string version in index.html after changing that asset so browsers request the latest file.
3. Add new public HTML pages to sitemap.xml.
4. Check desktop and mobile layouts, navigation, download links and keyboard focus states.

## Accessibility and search

The site includes a skip link, semantic page landmarks, descriptive image text, visible keyboard focus, reduced-motion handling, canonical URL metadata, Open Graph metadata, Person structured data, robots.txt and an XML sitemap.
